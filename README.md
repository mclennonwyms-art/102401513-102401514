# 拾光：校园失物招领 Web 程序

“拾光”是根据第一次结对作业原型完成的校园失物招领网页。项目使用原生 HTML、CSS 和 JavaScript，不依赖服务器或第三方框架，下载后可直接使用谷歌浏览器打开。

GitHub仓库：[mclennonwyms-art/102401513-102401514](https://github.com/mclennonwyms-art/102401513-102401514)

## 已实现功能

- 浏览全部、寻物和招领信息
- 发布寻物信息或招领信息，并检查必填内容
- 通过物品名称、地点、类别和特征进行关键词搜索
- 按信息类型、物品类别和校园区域组合筛选
- 查看物品详情，先隐藏再查看、复制发布者联系方式
- 在“我的发布”中将信息标记为“已找到”或“已归还”
- 撤回自己的发布；撤回后不再公开显示，并可随时恢复
- 自动保存发布内容、搜索记录和状态变化
- 提供搜索无结果、表单填写错误等提示

## 使用方法

1. 下载并解压整个项目，不能只下载 `index.html`。
2. 进入 `dist` 文件夹。
3. 使用谷歌浏览器打开 `index.html`。
4. 首页可以浏览信息；底部按钮依次进入首页、搜索、发布和我的发布。

网页数据保存在当前浏览器的 `localStorage` 中。刷新或关闭页面后，自己发布的信息仍然存在。若要回到初始状态，可进入“我的”并点击“恢复示例”。

## 推荐测试流程

1. 在首页切换“全部、寻物、招领”，打开任意信息详情。
2. 在搜索页输入“校园卡”，再按类别或区域筛选。
3. 搜索一个不存在的名称，检查无结果提示。
4. 进入发布页，先直接提交，检查必填提示。
5. 填写完整信息并发布，检查首页和“我的发布”是否出现新内容。
6. 打开新内容详情，查看并复制联系方式。
7. 在“我的发布”中修改状态，再回首页检查状态是否同步。
8. 撤回一条自己的信息，检查首页中是否消失，再从“我的发布”恢复。

## 运行自动化测试

需要安装 Node.js 18 或更高版本。在项目根目录运行：

```bash
node --test tests/core.test.js
```

测试不需要安装 npm 包。当前共有 22 个测试，覆盖搜索、筛选、发布校验、信息创建、状态修改、撤回与恢复、联系方式隐藏、搜索记录和输入安全处理。

## 数据说明

本项目是课程作业，没有连接真实服务器。所有新增信息只保存在打开网页的浏览器中，不会上传到网络。示例联系方式均为虚构内容。
