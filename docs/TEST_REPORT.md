# 拾光自动化测试说明

## 测试工具

项目使用 Node.js 自带的 `node:test` 和 `node:assert`。选择它们的原因是无需下载额外工具，其他同学取得项目后可以直接运行测试。

运行命令：

```bash
node --test tests/core.test.js
```

## 测试数据设计

测试数据包含寻物和招领、进行中、已结束和已撤回、本人发布和他人发布、不同类别与不同区域。除正常流程外，还检查了空内容、描述过短、重复修改、没有权限修改、撤回与恢复和特殊字符等情况。这些测试能够覆盖本项目主要的数据处理函数，但不能完全替代人工点击，因此提交前还应按照 README 中的推荐流程在谷歌浏览器中检查页面。
