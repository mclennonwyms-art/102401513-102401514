# 墨刀导入清单

新建手机原型，画布设为 **390 × 844**。将 `images/v2/` 中的 PNG 按下表建立页面；图片铺满画布并锁定，再用透明矩形添加点击热区。

| 墨刀页面名 | 对应图片 | 主要交互 |
| --- | --- | --- |
| 01 首页 | `01-home.png` | 搜索框→04；信息卡→10；发布→09 |
| 02 首页加载 | `02-home-loading.png` | 自动跳转→01 |
| 03 首页失败 | `03-home-error.png` | 重新加载→02 |
| 04 搜索输入 | `04-search-idle.png` | 搜索按钮/历史词→06 |
| 05 搜索结果 | `05-search-results.png` | 信息卡→10；筛选按钮→08 |
| 06 搜索加载 | `06-search-loading.png` | 自动跳转→05 |
| 07 搜索无结果 | `07-search-empty.png` | 清除筛选→05 |
| 08 筛选展开 | `08-filter-open.png` | 查看结果→05；遮罩区→05 |
| 09 发布信息 | `09-publish.png` | 立即发布→11 |
| 10 信息详情 | `10-detail.png` | 返回→01；复制方式→提示状态 |
| 11 发布成功 | `11-success.png` | 查看我的发布→12；返回首页→01 |
| 12 我的发布 | `12-mine.png` | 查看详情→10；首页→01 |

完成后在墨刀右上角选择“预览”，逐条走查；再选择“分享”，设置全部页面可见并复制公开链接。博客 `BLOG.md` 中的“墨刀链接”需要替换成最终地址。
